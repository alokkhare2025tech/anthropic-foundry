# CCA-F(Unofficial) Mock Exam: Claude Certified Architect

A comprehensive, exam-aligned mock testing platform for the **Claude Certified Architect – Foundations (CCA-F)** certification. Prepare for the official Anthropic exam with 60 high-quality questions covering all five certification domains.

## 🚀 Live Demo
Access the live mock exam platform and simulate the real CCA-F certification experience:

👉 https://mominurr.github.io/cca-f-mock-exam

## ✨ Features

- **Exam-Aligned Content:** 60 questions designed to match the difficulty and topic coverage of the official CCA-F exam.
- **Realistic Environment:** Includes a 120-minute timer and an auto-submit feature to simulate actual testing conditions.
- **Detailed Analytics:** Get a scaled score (100–1000) and a performance breakdown by domain.
- **Deep Explanations:** Every question includes a thorough explanation of the correct answer and specific justifications for why incorrect options are wrong.
- **Session Persistence:** Progress is automatically saved to `localStorage`, allowing you to resume your exam if you refresh or close the browser.
- **Mobile Responsive:** Study anywhere with a UI optimized for desktop, tablet, and smartphone.
- **Dark Mode Support:** Switch between light and dark themes for comfortable late-night study sessions.

## 🖥️ Getting Started

### Local Development
Since this is a purely client-side application, you can run it without any local server:
1. Clone the repository.
2. Open `index.html` in your preferred web browser.

### Deployment (GitHub Pages)
1. Push this repository to GitHub.
2. Go to **Settings > Pages**.
3. Under "Build and deployment", set the source to "Deploy from a branch" and select `main` (root).
4. Your mock exam will be live at `https://<username>.github.io/<repo-name>/`.
