## Why this is in the repo

CCDV-F is **not** the exam this repo targets. It is the sibling *developer* credential.
Keeping the distinction explicit avoids studying the wrong blueprint:

| | CCAR-F (this repo) | CCDV-F |
|---|---|---|
| Track | Architect | Developer |
| Focus | Designing agentic systems, orchestration, reliability | Building and shipping Claude-powered applications |
| Domains | 5 | 7 |

## CCDV-F domains

1. Applications and Integration
2. Model Selection and Optimization
3. Agents and Workflows
4. Prompt and Context Engineering
5. Tools and MCPs
6. Security and Safety
7. AI Evaluation, Testing, and Debugging

## Audience and prerequisites

Aimed at AI engineers, software developers, ML specialists and technical architects.
Assumed background: Python or TypeScript, REST API integration, LLM fundamentals, and
familiarity with AI agent concepts.

## Overlap worth exploiting

Domains 3, 4 and 5 of CCDV-F overlap heavily with CCAR-F Domains 1, 2 and 4. Roughly half
of the question bank in this repo is useful revision for both. The parts that do **not**
transfer are CCDV-F's Model Selection/Optimization and Security/Safety domains, which
CCAR-F barely touches.

A fuller write-up of the sibling certifications (CCAO-F, CCAR-P, CCDV-F) is archived at
[`sources/dnacenta/certs/`](../dnacenta/certs/).
